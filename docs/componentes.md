# Tabla de componentes

| Componente | Cantidad | Función en el invernadero |
|---|---|---|
| Arduino Uno R3 | 1 | Cerebro del sistema |
| DHT11 | 1 | Temperatura y humedad del aire |
| Fotorresistencia (LDR) + resistencia 10 kΩ | 1 | Nivel de luz |
| Sensor de nivel de agua (placa roja) | 1 | Humedad de la tierra, clavado en una maceta |
| Módulo relé de 1 canal | 1 | Riego (simulado con LED, o bomba real si se consigue) |
| Servo 9G | 1 | Abre y cierra la ventana de ventilación |
| Motor paso a paso 28BYJ-48 + driver ULN2003 | 1 | Cortina de sombra (opcional) |
| LCD 1602 con módulo I2C | 1 | Muestra los datos y el estado |
| Módulo RTC | 1 | Hora real y horarios de riego |
| Buzzer activo | 1 | Alarmas |
| LEDs verde, amarillo y rojo + 3 resistencias de 220 Ω | 3 | Indicadores de estado |
| Pulsadores | 2 | Riego manual y cambio de pantalla |
| Protoboard y jumpers | - | Conexiones |
